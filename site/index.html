01

现代 Webmail

会话阅读、全文搜索、草稿、定时发送、标签、自定义文件夹、联系人、签名、导入导出和多邮箱切换；三套模板适配移动端与超宽屏。

可视化管理后台

账号、权限、域名、DNS、邮箱、队列、全域公告、三语言默认设置、界面模板和系统统计集中管理。

03

默认重视安全

TOTP 双因素、恢复码、应用密码、API scope、Webhook 签名和 SSRF 防护。

2FADKIMTLS
04

标准邮件协议

SMTP Submission、IMAP SSL 和 POP3 SSL，兼容主流桌面与移动客户端。

SMTPIMAPPOP3

备份、更新与回滚

更新前自动备份，后台异步更新，保留上一镜像并支持二次确认回滚。

开放 API 与自动化

通过 `/api/open/v1` 管理域名、邮箱和邮件投递；状态 Webhook 带签名、重试与幂等保护。

POST /api/open/v1/send { "to": "hello@example.com" } 202 Accepted
清晰的系统边界

复杂的邮件栈，
简单地交给你。

默认 All-in-one 镜像将成熟的邮件组件组合在一起。账号、设置和索引写入 SQLite，邮件原文留在 Maildir，所有关键数据都持久化在宿主机。

  • ✓
    一套 Compose业务服务与内部更新服务职责分离
  • ✓
    标准组件Postfix、Dovecot、Rspamd，不重新发明邮件协议
  • ✓
    数据可迁移.env、data、mail、dkim 成套备份即可恢复
